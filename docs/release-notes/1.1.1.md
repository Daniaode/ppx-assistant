## 1.1.1

### 变更
- **项目更名为「皮友助手」**，仓库地址迁移为
  `https://github.com/Daniaode/piyou-assistant`（旧地址自动重定向）
- 模块内置的「检查更新」地址同步指向新仓库
- 新增发布流程文档 `docs/RELEASE.md` 与一键脚本 `tools/release.sh`
- 新增 GitHub Actions 工作流 `merge-release-assets.yml`：
  分片资产在 GitHub 侧自动拼接、校验、上传为单个 APK，并清理分片

### 背景
跨境链路上传 100MB+ 单文件会中途被重置（实测 10~490 KB/s 波动），
GitHub 单资产上限其实是 2GB，所以限制来自链路而非平台。
现在改为「本地分片上传 + GitHub 侧合并」，发布页始终只保留一个完整 APK。

### 安装
覆盖安装即可，设置不丢失；装完强停皮皮虾再打开。
